# LeadPilot Design Philosophy

Design principles and inspiration details.

---

## 1. Inspirations
LeadPilot draws inspiration from top-tier technology companies:
* **Stripe**: Slick, thin border dividers, dark slate layouts, and colored grid presets.
* **Apple**: Scroll-driven viewport scaling and rounded container expansions.
* **Linear / Vercel**: High contrast dark aesthetics, subtle text colors, and green pulsing status lights.

---

## 2. Key Design Codes
* **High Information Density**: Cards are filled with realistic data models (calendar cells, logs, numbers), avoiding empty placeholder blocks.
* **Subtle Highlights**: Avoid strong grid lines. Borders are thin, semi-transparent, and use backdrop blur layers.
