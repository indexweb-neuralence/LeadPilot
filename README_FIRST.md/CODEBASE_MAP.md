## 2. File Roles
* **`meeting-booking.html`**: Core marketing page containing the redesigned timeline.
* **`how-it-works-dark.tsx`**: Component mirror of the showcase timeline inside React/Tailwind workspaces.
* **`demo.tsx`**: Test component mounting wrapper.
* **`server.py`**: Lightweight Python web server on port 3000.
