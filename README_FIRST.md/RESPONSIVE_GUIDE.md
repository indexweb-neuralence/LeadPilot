# LeadPilot Responsive Layout Guide

Implementation metrics for responsive alignments.

---

## 1. Breakpoints
* **Mobile**: `< 768px` (Stacks cards in one column, reduces titles to 32px, hides connectors).
* **Tablet**: `768px - 1024px` (Two column grids, hides connectors).
* **Desktop**: `> 1024px` (Horizontal cards row, circular chevrons connectors active, full grids).

---

## 2. Spacing Scaling
* Container paddings scale from `40px` (desktop) to `24px` (mobile).
* Grid gaps decrease from `24px` to `16px`.
