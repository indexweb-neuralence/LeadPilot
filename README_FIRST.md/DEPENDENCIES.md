# LeadPilot Dependencies Inventory

Third-party libraries used in the LeadPilot codebase.

---

## 1. Frontend Core
* **React**: Virtual DOM framework.
* **Framer Motion**: React animation system (`useScroll`, `useTransform`, `motion`).
* **Tailwind CSS**: Utility-first CSS compiling library.
* **Lucide React / Lucide Icons**: Consistent, clean outline icon library.

---

## 2. Backend / Server Utilities
* **Python 3.x (with http.server)**: Serves static assets, routing headers, and HTML files during development.
