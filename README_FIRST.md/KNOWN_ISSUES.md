# LeadPilot Known Issues & Constraints

Active issues, limitations, and future cleanup points.

---

## 1. Environment Constraints
* **Browser Automation Agent**: Automated visual tests run via Chrome DevTools are Linux-only and cannot run on macOS workspaces due to sandbox restrictions.

---

## 2. Layout & Style Constraints
* **Content Scaling**: Infographics in Card 1 require fixed sizing grids to prevent time slot buttons or calendar columns from wrapping onto multiple lines on small screen widths.
