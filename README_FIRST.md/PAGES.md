# LeadPilot Page Documentation

Architectural blueprints for each website page.

---

## 1. Home Page (`index.html`)
* **Purpose**: Introduce LeadPilot value proposition.
* **Main Sections**: Hero, Background Particle Canvas, Product Bento grids, pricing options, testimonials.
* **Animations**: Canvas particles emitter loop.

---

## 2. Meeting Booking Page (`meeting-booking.html`)
* **Purpose**: Showcase the branded scheduler, routing rules, and CRM syncing.
* **Main Sections**: Hero, Rebuilt "How It Works" dark showcase module, Bento grid features.
* **Interactions**:
  - Scroll-driven viewport container expansion.
  - Theme preset color chip click selectors.

---

## 3. Lead Forms Page (`lead-forms.html`)
* **Purpose**: Inbound forms overview.
* **Aesthetics**: Modern dark grid panels.

---

## 4. Lead Generator Page (`lead-generator.html`)
* **Purpose**: Outbound campaigns overview.
* **Aesthetics**: Clean layout structures with outline icons.
