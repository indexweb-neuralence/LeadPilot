# LeadPilot Components Documentation

Detailed specifications for every visual component.

---

## 1. Global Navigation Bar (`#navbar`)
* **Purpose**: Page navigation, logo display, action links.
* **Aesthetics**: Glassmorphic floating header, blur filter, subtle border, logo text on left, CTAs on right.
* **Responsive**: Stacks to a mobile drawer menu.

---

## 2. Hero Background Particle Canvas
* **Purpose**: Ambient landing page decoration.
* **Implementation**: HTML5 `<canvas>` element mapping floating particles with gradient connector links. Updates dynamically via requestAnimationFrame loop.

---

## 3. Card 01 — Branded Booking Forms Mockup
* **Purpose**: Product illustration for custom theme builders.
* **Sub-components**:
  - Browser header chrome with traffic lights.
  - Left panel detailing brand metadata and descriptors.
  - Right panel calendar grid (May 2026 starting on Friday) with cell 19 highlighted, active slots.
  - Theme customizer pills row.

---

## 4. Card 02 — Lead Routing Pipeline
* **Purpose**: Visual workflow detailing lead assignment.
* **Sub-components**:
  - Dotted vertical lines with traveling dot pulse indicators.
  - 4 status nodes detailing booked meetings, qualifications, rule matches, assignments.
  - Assigned representative gradient card.

---

## 5. Card 03 — CRM capture log
* **Purpose**: Visual illustration of automatic pipelines database updates.
* **Sub-components**:
  - Activity feed check logs.
  - Lead status and Pipeline KPI dashboard widget cards.
  - Connected horizontal reminder nodes workflow.
  - LeadPilot sync logo status footer bar.

---

## 6. Benefit Strip Glass Bar
* **Purpose**: Bottom showcase benefits row.
* **Sub-components**:
  - Left column (Built for more bookings) with a sparkles icon.
  - 6 subsequent columns mapping conversions, security, analytics, and automation.
